## Usage

```tsx showLineNumbers
import {
  OTPField,
  OTPFieldGroup,
  OTPFieldInput,
  OTPFieldSeparator,
  OTPFieldSlot,
} from "~/components/ui/otp-field"
```

```tsx showLineNumbers
<OTPField maxLength={6}>
  <OTPFieldInput />
  <OTPFieldGroup>
    <OTPFieldSlot index={0} />
    <OTPFieldSlot index={1} />
    <OTPFieldSlot index={2} />
  </OTPFieldGroup>
  <OTPFieldSeparator />
  <OTPFieldGroup>
    <OTPFieldSlot index={3} />
    <OTPFieldSlot index={4} />
    <OTPFieldSlot index={5} />
  </OTPFieldGroup>
</OTPField>
```

## Composition

Use the following composition to build an `OTPField`:

```text
OTPField
├── OTPFieldInput
├── OTPFieldGroup
│   ├── OTPFieldSlot
│   ├── OTPFieldSlot
│   └── OTPFieldSlot
├── OTPFieldSeparator
├── OTPFieldGroup
│   ├── OTPFieldSlot
│   ├── OTPFieldSlot
│   └── OTPFieldSlot
├── OTPFieldSeparator
└── OTPFieldGroup
    ├── OTPFieldSlot
    └── OTPFieldSlot
```

## Pattern

Use the `pattern` prop to define a custom pattern for the OTP input.

```tsx showLineNumbers {1,4}
import { REGEXP_ONLY_DIGITS_AND_CHARS } from "~/components/ui/otp-field"

;<OTPField maxLength={6}>
  <OTPFieldInput pattern={REGEXP_ONLY_DIGITS_AND_CHARS} />
  ...
</OTPField>
```

## API Reference

See the [Corvu OTP Field documentation](https://corvu.dev/docs/primitives/otp-field/) for the full API reference.

### OTPField

The `OTPField` component is the wrapper that positions the hidden input and
provides the context to the slots.

| Prop            | Type                      | Default |
| --------------- | ------------------------- | ------- |
| `maxLength`     | `number`                  | -       |
| `value`         | `string`                  | -       |
| `onValueChange` | `(value: string) => void` | -       |
| `onComplete`    | `(value: string) => void` | -       |
| `class`         | `string`                  | -       |

### OTPFieldInput

The `OTPFieldInput` component renders the hidden `input` element and accepts
every native input attribute, including `id`, `disabled` and `required`.

| Prop      | Type             | Default    |
| --------- | ---------------- | ---------- |
| `pattern` | `string \| null` | `"^\\d*$"` |
| `class`   | `string`         | -          |

### OTPFieldGroup

The `OTPFieldGroup` component groups slots together. Use several groups with
an `OTPFieldSeparator` between them to split the field into sections.

### OTPFieldSlot

The `OTPFieldSlot` component renders a single character of the value.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `index` | `number` | -       |
| `class` | `string` | -       |

Set `aria-invalid` on a slot to render its error state. See the
[invalid](#invalid) example for more details.

### OTPFieldSeparator

The `OTPFieldSeparator` component visually divides two groups of slots.
