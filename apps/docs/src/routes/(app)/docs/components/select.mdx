## Usage

```tsx showLineNumbers
import {
  Select,
  SelectContent,
  SelectItem,
  SelectTrigger,
  SelectValue
} from "~/components/ui/select"
```

```tsx showLineNumbers
const fruits = ["Apple", "Banana", "Blueberry", "Grapes", "Pineapple"]

export function ExampleSelect() {
  return (
    <Select
      class="w-full max-w-48"
      options={fruits}
      placeholder="Select a fruit"
      itemComponent={(props) => (
        <SelectItem item={props.item}>{props.item.rawValue}</SelectItem>
      )}
    >
      <SelectTrigger aria-label="Fruit" class="w-full">
        <SelectValue<string>>{(state) => state.selectedOption()}</SelectValue>
      </SelectTrigger>
      <SelectContent />
    </Select>
  )
}
```

## Composition

Kobalte builds the list from the `options` prop instead of children, so items
render through `itemComponent` and `SelectContent` renders the listbox itself.
`Select` also renders a real wrapper element around the trigger, so size the
wrapper and let `SelectTrigger` fill it with `class="w-full"`.

```text
Select
├── SelectTrigger
│   └── SelectValue
└── SelectContent
    ├── SelectItem
    └── SelectItem
```

### With groups

Nested items per group using the `optionGroupChildren` prop, with group labels
rendered through `sectionComponent` and a `SelectSeparator` between groups (see
[Groups](#groups)).

```text
Select
├── SelectTrigger
│   └── SelectValue
└── SelectContent
    ├── SelectSection
    ├── SelectItem
    ├── SelectItem
    ├── SelectSeparator
    ├── SelectSection
    ├── SelectItem
    └── SelectItem
```

## Invalid

Add the `data-invalid` attribute to the `Field` component and set
`validationState="invalid"` on the `Select` component to show an error state.
The `aria-invalid` attribute on `SelectTrigger` styles it the same way.

```tsx showLineNumbers /data-invalid/ /validationState/
<Field data-invalid>
  <FieldLabel>Fruit</FieldLabel>
  <Select validationState="invalid" options={fruits} itemComponent={...}>
    <SelectTrigger>
      <SelectValue />
    </SelectTrigger>
    <SelectContent />
  </Select>
</Field>
```
