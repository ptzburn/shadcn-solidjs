## Usage

```tsx showLineNumbers
import { Calendar } from "~/components/ui/calendar"
```

```tsx showLineNumbers
const [date, setDate] = createSignal<Date | null>(new Date())

return (
  <Calendar
    mode="single"
    value={date()}
    onValueChange={setDate}
    class="rounded-lg border"
  />
)
```

See the [Corvu Calendar](https://corvu.dev/docs/primitives/calendar/) documentation for more information.

## Date Picker

You can use the `<Calendar>` component to build a date picker. Render it inside a `<PopoverContent>`, or see the [Date Picker](/docs/components/date-picker) page for a dedicated picker with an input.

## Custom Cell Size

<ComponentPreview name="calendar-custom-days" previewClassName="h-[560px]" />

You can customize the size of calendar cells using the `--cell-size` CSS variable. You can also make it responsive by using breakpoint-specific values:

```tsx showLineNumbers
<Calendar
  mode="single"
  value={date()}
  onValueChange={setDate}
  class="rounded-lg border [--cell-size:--spacing(11)] md:[--cell-size:--spacing(12)]"
/>
```

Or use fixed values:

```tsx showLineNumbers
<Calendar
  mode="single"
  value={date()}
  onValueChange={setDate}
  class="rounded-lg border [--cell-size:2.75rem] md:[--cell-size:3rem]"
/>
```

The example above also passes a custom `DayButton` through the `components` prop to render a price under every day.

## API Reference

See the [Corvu Calendar documentation](https://corvu.dev/docs/primitives/calendar/) for the full API reference.

### Calendar

The `Calendar` component renders the navigation, caption and month grids. It
accepts every prop of the Corvu `Calendar` root, plus the ones below.

| Prop                  | Type                                                         | Default   |
| --------------------- | ------------------------------------------------------------ | --------- |
| `mode`                | `"single" \| "multiple" \| "range"`                           | -         |
| `value`               | `Date \| null` · `Date[]` · `{ from: Date \| null; to: Date \| null }` | -  |
| `onValueChange`       | `(value) => void`                                            | -         |
| `initialValue`        | same as `value`                                              | -         |
| `month`               | `Date`                                                       | -         |
| `onMonthChange`       | `(month: Date) => void`                                      | -         |
| `initialMonth`        | `Date`                                                       | today     |
| `numberOfMonths`      | `number`                                                     | `1`       |
| `disabled`            | `(day: Date) => boolean`                                     | -         |
| `required`            | `boolean`                                                    | `false`   |
| `startOfWeek`         | `number`                                                     | `1`       |
| `fixedWeeks`          | `boolean`                                                    | `false`   |
| `disableOutsideDays`  | `boolean`                                                    | `true`    |
| `showOutsideDays`     | `boolean`                                                    | `true`    |
| `showWeekNumber`      | `boolean`                                                    | `false`   |
| `captionLayout`       | `"label" \| "dropdown" \| "dropdown-months" \| "dropdown-years"` | `"label"` |
| `buttonVariant`       | `ButtonProps["variant"]`                                     | `"ghost"` |
| `startMonth`          | `Date`                                                       | -         |
| `endMonth`            | `Date`                                                       | -         |
| `locale`              | `string`                                                     | `"en-US"` |
| `formatters`          | `Partial<CalendarFormatters>`                                | -         |
| `modifiers`           | `Record<string, (day: Date) => boolean>`                     | -         |
| `modifiersClassNames` | `Record<string, string>`                                     | -         |
| `components`          | `{ DayButton?: Component<CalendarDayButtonProps> }`          | -         |
| `class`               | `string`                                                     | -         |

`startOfWeek` counts from Sunday (`0`), so the default starts weeks on
Monday. Outside days, the ones that belong to the previous or next month, are
shown but not selectable by default; pass `disableOutsideDays={false}` to make
them selectable or `showOutsideDays={false}` to hide them.

`startMonth` and `endMonth` bound the navigation buttons and the dropdown
ranges. Without them, the year dropdown lists the past hundred years.

Dates and weekday names are formatted with `Intl` using `locale`. Override
any of `formatCaption`, `formatMonthDropdown`, `formatYearDropdown`,
`formatWeekdayName`, `formatWeekNumber` and `formatDay` through `formatters`;
each receives the date and the locale.

### CalendarDayButton

The `CalendarDayButton` component renders a single day. It is the default
`DayButton` and the one to wrap when you pass your own through `components`.

| Prop        | Type                | Default |
| ----------- | ------------------- | ------- |
| `day`       | `Date`              | -       |
| `month`     | `Date`              | -       |
| `modifiers` | `CalendarModifiers` | -       |
| `class`     | `string`            | -       |

`modifiers` carries `selected`, `rangeStart`, `rangeEnd`, `rangeMiddle`,
`today`, `outside`, `disabled` and `hidden`, plus any custom modifier you
declared on the calendar.
