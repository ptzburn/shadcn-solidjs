## Usage

```tsx
import { Label } from "~/components/ui/label"
import { RadioGroup, RadioGroupItem } from "~/components/ui/radio-group"
```

```tsx showLineNumbers
<RadioGroup defaultValue="option-one">
  <div class="flex items-center gap-3">
    <RadioGroupItem value="option-one" id="option-one" />
    <Label for="option-one-input">Option One</Label>
  </div>
  <div class="flex items-center gap-3">
    <RadioGroupItem value="option-two" id="option-two" />
    <Label for="option-two-input">Option Two</Label>
  </div>
</RadioGroup>
```

`RadioGroupItem` renders a visually hidden `<input type="radio">` alongside the
control. The input's id is the item's id with an `-input` suffix, so a `Label`
or `FieldLabel` points at `<item-id>-input`.

Alternatively, pass a `RadioGroupItemLabel` as a child of `RadioGroupItem` and
Kobalte wires the label to the input for you.

```tsx showLineNumbers
<RadioGroup defaultValue="option-one">
  <RadioGroupItem value="option-one">
    <RadioGroupItemLabel>Option One</RadioGroupItemLabel>
  </RadioGroupItem>
  <RadioGroupItem value="option-two">
    <RadioGroupItemLabel>Option Two</RadioGroupItemLabel>
  </RadioGroupItem>
</RadioGroup>
```

## Composition

Use the following composition to build a `RadioGroup`:

```text
RadioGroup
├── RadioGroupItem
│   └── RadioGroupItemLabel
└── RadioGroupItem
    └── RadioGroupItemLabel
```
