## Usage

```tsx
import {
  Switch,
  SwitchControl,
  SwitchLabel,
  SwitchThumb,
} from "~/components/ui/switch"
```

```tsx showLineNumbers
<Switch>
  <SwitchControl>
    <SwitchThumb />
  </SwitchControl>
  <SwitchLabel>Airplane Mode</SwitchLabel>
</Switch>
```

`SwitchControl` renders a visually hidden `<input type="checkbox">` alongside
the control. The input's id is the switch's id with an `-input` suffix, so a
`Label` or `FieldLabel` outside the switch points at `<switch-id>-input`.

```tsx showLineNumbers
<Field orientation="horizontal">
  <Switch id="airplane-mode">
    <SwitchControl>
      <SwitchThumb />
    </SwitchControl>
  </Switch>
  <FieldLabel for="airplane-mode-input">Airplane Mode</FieldLabel>
</Field>
```

## Composition

Use the following composition to build a `Switch`:

```text
Switch
├── SwitchControl
│   └── SwitchThumb
└── SwitchLabel
```

## Disabled

Add the `disabled` prop to the `Switch` component to disable the switch. Add the `data-disabled` prop to the `Field` component for styling.

<ComponentPreview name="switch-disabled" />

## Invalid

Add `validationState="invalid"` to the `Switch` component to indicate an invalid state. Add the `data-invalid` prop to the `Field` component for styling.

<ComponentPreview name="switch-invalid" />
