## Usage

```tsx showLineNumbers
import {
  InputOTP,
  InputOTPGroup,
  InputOTPInput,
  InputOTPSeparator,
  InputOTPSlot,
} from "~/components/ui/input-otp"
```

```tsx showLineNumbers
<InputOTP maxLength={6}>
  <InputOTPInput />
  <InputOTPGroup>
    <InputOTPSlot index={0} />
    <InputOTPSlot index={1} />
    <InputOTPSlot index={2} />
  </InputOTPGroup>
  <InputOTPSeparator />
  <InputOTPGroup>
    <InputOTPSlot index={3} />
    <InputOTPSlot index={4} />
    <InputOTPSlot index={5} />
  </InputOTPGroup>
</InputOTP>
```

## Composition

Use the following composition to build an `InputOTP`:

```text
InputOTP
├── InputOTPInput
├── InputOTPGroup
│   ├── InputOTPSlot
│   ├── InputOTPSlot
│   └── InputOTPSlot
├── InputOTPSeparator
├── InputOTPGroup
│   ├── InputOTPSlot
│   ├── InputOTPSlot
│   └── InputOTPSlot
├── InputOTPSeparator
└── InputOTPGroup
    ├── InputOTPSlot
    └── InputOTPSlot
```

## Pattern

The input accepts any character by default. Use the `pattern` prop to restrict
what can be entered.

```tsx showLineNumbers {1,4}
import { REGEXP_ONLY_DIGITS_AND_CHARS } from "~/components/ui/input-otp"

;<InputOTP maxLength={6}>
  <InputOTPInput pattern={REGEXP_ONLY_DIGITS_AND_CHARS} />
  ...
</InputOTP>
```

## API Reference

See the [Corvu OTP Field documentation](https://corvu.dev/docs/primitives/otp-field/) for the full API reference.

### InputOTP

The `InputOTP` component is the wrapper that positions the hidden input and
provides the context to the slots.

| Prop            | Type                      | Default |
| --------------- | ------------------------- | ------- |
| `maxLength`     | `number`                  | -       |
| `value`         | `string`                  | -       |
| `onValueChange` | `(value: string) => void` | -       |
| `onComplete`    | `(value: string) => void` | -       |
| `class`         | `string`                  | -       |

### InputOTPInput

The `InputOTPInput` component renders the hidden `input` element and accepts
every native input attribute, including `id`, `disabled` and `required`.

| Prop      | Type             | Default |
| --------- | ---------------- | ------- |
| `pattern` | `string \| null` | `null`  |
| `class`   | `string`         | -       |

By default any character is accepted. Pass a `pattern` to restrict input, or
`null` to explicitly allow everything.

### InputOTPGroup

The `InputOTPGroup` component groups slots together. Use several groups with
an `InputOTPSeparator` between them to split the field into sections.

### InputOTPSlot

The `InputOTPSlot` component renders a single character of the value.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `index` | `number` | -       |
| `class` | `string` | -       |

Set `aria-invalid` on a slot to render its error state. See the
[invalid](#invalid) example for more details.

### InputOTPSeparator

The `InputOTPSeparator` component visually divides two groups of slots.
