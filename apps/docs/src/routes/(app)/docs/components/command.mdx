## About

Command is built on top of [Kobalte Search](https://kobalte.dev/docs/core/components/search).
Items are passed as data through the `options` prop; the Kobalte collection
provides keyboard navigation and combobox semantics, and the palette filters
the options as you type.

## Usage

```tsx showLineNumbers
import { Command, CommandDialog } from "~/components/ui/command.tsx"
```

```tsx showLineNumbers
<Command
  placeholder="Type a command or search..."
  options={[
    {
      heading: "Suggestions",
      options: [
        { value: "calendar", label: "Calendar" },
        { value: "billing", label: "Billing", shortcut: "⌘B" },
        { value: "calculator", label: "Calculator", disabled: true },
      ],
    },
  ]}
  onSelect={(option) => console.log(option.value)}
/>
```

Each option can carry an `icon` (a function returning JSX), a `shortcut`
label, extra `keywords` for filtering, and its own `onSelect` handler.
`value` must be unique across all groups. Pass `emptyMessage` to replace the
default "No results found." text, and `filter`
(`(option, inputValue) => boolean`) to replace the label and keywords match.

`CommandDialog` takes the same props and renders the palette in a dialog
controlled with `open` and `onOpenChange`; `title` and `description` set its
visually hidden heading, and `showCloseButton` renders the close button.
