## About

Command is built on top of [Kobalte Search](https://kobalte.dev/docs/core/components/search).

Unlike the cmdk-based upstream component, items are passed as data through
the `options` prop rather than composed as JSX children: the Kobalte
collection supplies filtering, keyboard navigation, and combobox
semantics from that data.

## Usage

```tsx showLineNumbers
import { Command } from "~/components/ui/command.tsx";

<Command
  placeholder="Type a command or search..."
  options={[
    {
      heading: "Suggestions",
      options: [
        { value: "calendar", label: "Calendar" },
        { value: "billing", label: "Billing", shortcut: "⌘B" },
        { value: "calculator", label: "Calculator", disabled: true },
      ],
    },
  ]}
  onSelect={(option) => console.log(option.value)}
/>;
```

Each option can carry an `icon` (a function returning JSX), a `shortcut`
label, extra `keywords` for filtering, and its own `onSelect` handler.

## Dialog

Wrap the palette in a dialog with `CommandDialog` and control it with
`open`/`onOpenChange` — for example from a ⌘K shortcut.

```tsx showLineNumbers
import { CommandDialog } from "~/components/ui/command.tsx";
import { createSignal } from "solid-js";

function CommandMenu() {
  const [open, setOpen] = createSignal(false);

  createEffect(() => {
    const down = (e: KeyboardEvent) => {
      if (e.key === "k" && (e.metaKey || e.ctrlKey)) {
        e.preventDefault();
        setOpen((open) => !open);
      }
    };
    document.addEventListener("keydown", down);
    return () => document.removeEventListener("keydown", down);
  });

  return <CommandDialog open={open()} onOpenChange={setOpen} options={[]} />;
}
```
