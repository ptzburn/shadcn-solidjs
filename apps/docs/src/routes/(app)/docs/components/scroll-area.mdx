## Native Scrollbars

Kobalte has no scroll-area primitive, so this component is a single
scrollable `div` that restyles the browser's own scrollbar with
`scrollbar-width` and `scrollbar-color`.

That means there is no `ScrollBar` component to render and no viewport
wrapper — set the size on `ScrollArea` itself and put your content directly
inside it.

```tsx
<ScrollArea class="h-72 w-48 rounded-md border">
  <div class="p-4">{/* ... */}</div>
</ScrollArea>
```

<Callout>
  The scrollbar is the platform's, so its exact appearance follows the
  browser and operating system. `scrollbar-width` and `scrollbar-color` are
  supported by every current browser; where they are not, the area still
  scrolls with the default scrollbar.
</Callout>

## API Reference

### ScrollArea

A scrollable container. Renders a `div` and accepts every native attribute.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |
