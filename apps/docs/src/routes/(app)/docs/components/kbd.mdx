## API Reference

### Kbd

Use the `Kbd` component to display a keyboard key. It renders a `kbd` element
and accepts every native attribute.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |

```tsx
<Kbd>Ctrl</Kbd>
```

### KbdGroup

Use the `KbdGroup` component to group `Kbd` components together.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `class` | `string` | -       |

```tsx
<KbdGroup>
  <Kbd>Ctrl</Kbd>
  <Kbd>B</Kbd>
</KbdGroup>
```
