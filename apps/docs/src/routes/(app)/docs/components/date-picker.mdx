## About

The Date Picker component is built using [Ark UI](https://ark-ui.com/docs/components/date-picker). Unlike the original shadcn/ui, where the date picker is a composition of the `<Popover />` and the `<Calendar />` components, this component ships as a single `DatePicker` primitive with its own trigger, input, and calendar parts.

## Usage

```tsx showLineNumbers
import { Portal } from "solid-js/web"

import {
  DatePicker,
  DatePickerContent,
  DatePickerControl,
  DatePickerInput,
  DatePickerPositioner,
  DatePickerTrigger,
} from "~/components/ui/date-picker"
```

```tsx showLineNumbers
<DatePicker>
  <DatePickerControl>
    <DatePickerInput placeholder="Pick a date" />
    <DatePickerTrigger />
  </DatePickerControl>
  <Portal>
    <DatePickerPositioner>
      <DatePickerContent>{/* views */}</DatePickerContent>
    </DatePickerPositioner>
  </Portal>
</DatePicker>
```

See the [Ark UI Date Picker](https://ark-ui.com/docs/components/date-picker) documentation for more information.

## Composition

A date picker is composed from control, view, and table parts:

```text
DatePicker
├── DatePickerControl
│   ├── DatePickerInput
│   └── DatePickerTrigger
└── DatePickerPositioner
    └── DatePickerContent
        └── DatePickerView
            ├── DatePickerViewControl
            │   ├── DatePickerPrevTrigger
            │   ├── DatePickerViewTrigger or DatePickerRangeText
            │   └── DatePickerNextTrigger
            └── DatePickerTable
```
