## Usage

Add the `Toaster` component once at the root of your app. It renders the
toast region every toast appears in.

```tsx showLineNumbers
import { Toaster } from "~/components/ui/toast.tsx";

export default function App() {
  return (
    <>
      <Main />
      <Toaster />
    </>
  );
}
```

Then show toasts from anywhere with the `toast` helper.

```tsx showLineNumbers
import { toast } from "~/components/ui/toast.tsx";

const id = toast.add({
  title: "Event created",
  description: "Sunday, December 3 at 9:00 AM",
});

toast.close(id);
```
