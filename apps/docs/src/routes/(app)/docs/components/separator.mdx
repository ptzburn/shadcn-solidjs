## API Reference

### Separator

The `Separator` component renders a `div` and accepts every native div
attribute.

| Prop          | Type                          | Default        |
| ------------- | ----------------------------- | -------------- |
| `orientation` | `"horizontal" \| "vertical"`  | `"horizontal"` |
| `decorative`  | `boolean`                     | `true`         |
| `class`       | `string`                      | -              |

See the [Kobalte](https://kobalte.dev/docs/core/components/separator)
documentation for more information.
