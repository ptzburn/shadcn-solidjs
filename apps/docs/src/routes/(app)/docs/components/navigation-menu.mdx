## Usage

```tsx showLineNumbers
import {
  NavigationMenu,
  NavigationMenuContent,
  NavigationMenuItem,
  NavigationMenuLink,
  NavigationMenuTrigger,
} from "~/components/ui/navigation-menu"
```

```tsx showLineNumbers
<NavigationMenu>
  <NavigationMenuItem>
    <NavigationMenuTrigger>Item One</NavigationMenuTrigger>
    <NavigationMenuContent>
      <NavigationMenuLink href="/link">Link</NavigationMenuLink>
    </NavigationMenuContent>
  </NavigationMenuItem>
</NavigationMenu>
```

## Composition

Use the following composition to build a `NavigationMenu`:

```text
NavigationMenu
├── NavigationMenuItem
│   ├── NavigationMenuTrigger
│   └── NavigationMenuContent
│       ├── NavigationMenuLink
│       └── NavigationMenuLink
└── NavigationMenuTrigger (as="a")
```

Kobalte merges Radix's `Root` and `List` into a single primitive, so there is no
`NavigationMenuList`: `NavigationMenu` renders the list itself. `NavigationMenuItem`
only provides context — the `<li>` wrappers come from `NavigationMenuTrigger` and
`NavigationMenuLink`. `NavigationMenu` renders the viewport and
`NavigationMenuContent` portals itself into it.

Kobalte also has no `NavigationMenuIndicator`. Its closest primitive,
`NavigationMenu.Arrow`, must live inside the viewport and derives its own fill and
stroke from the viewport's computed style, so it is not exported here.

## Viewport

Every `NavigationMenuContent` is portalled into a single shared viewport that
animates between menus. Set `viewport={false}` to render each content in place
instead, styled like a popover.

```tsx showLineNumbers
<NavigationMenu viewport={false}>
  <NavigationMenuItem>
    <NavigationMenuTrigger>Item One</NavigationMenuTrigger>
    <NavigationMenuContent>
      <NavigationMenuLink href="/link">Link</NavigationMenuLink>
    </NavigationMenuContent>
  </NavigationMenuItem>
</NavigationMenu>
```

Three things to know about this mode. Kobalte's `NavigationMenuItem`
renders no element, so the content is anchored to the menu bar and aligned with
its left edge rather than to the item it belongs to. The content stays
absolutely positioned at every width; because the menu bar is what it is
positioned against, it is held to the width of the bar on a small screen rather
than to the width of the screen. And Kobalte keeps a content mounted through its exit animation only while
a viewport is there to watch, so the content disappears immediately on close
instead of animating out.

Kobalte wires its escape handling into the viewport, so with no viewport the menu
would only close on an outside click. `NavigationMenu` closes it on `Escape`
itself in this mode, which means it takes over `value` — pass `value` and
`onValueChange` to control it, as usual.

## Link Component

Use the `as` prop to compose a custom link component such as the router's `A`.

```tsx showLineNumbers
import { A } from "@solidjs/router"

import {
  NavigationMenuContent,
  NavigationMenuLink,
} from "~/components/ui/navigation-menu"

export function NavigationMenuDemo() {
  return (
    <NavigationMenuContent>
      <NavigationMenuLink as={A} href="/docs">
        Documentation
      </NavigationMenuLink>
    </NavigationMenuContent>
  )
}
```

## Top Level Links

`NavigationMenuLink` belongs inside `NavigationMenuContent`, where Kobalte manages
its focus. A link that sits directly in the menu bar goes on
`NavigationMenuTrigger` instead: Kobalte turns a trigger that carries an `href`
into a plain menu bar link, so it stays in the menu's keyboard navigation, it
opens nothing, and it renders no chevron. It already carries
`navigationMenuTriggerStyle()`, so it needs no extra styling.

```tsx showLineNumbers
<NavigationMenu>
  <NavigationMenuTrigger as="a" href="/docs">Docs</NavigationMenuTrigger>
</NavigationMenu>
```

Because such a link is a trigger, it carries `[data-slot=navigation-menu-trigger]`
and not `[data-slot=navigation-menu-link]`: styling written against the link slot
does not reach top-level links, which are styled through the trigger slot and
`navigationMenuTriggerStyle()`.

## Label and Description

`NavigationMenuLabel` and `NavigationMenuDescription` are Kobalte-only slots that
wire a link's `aria-labelledby` and `aria-describedby`.

```tsx showLineNumbers
<NavigationMenuLink href="/docs">
  <div class="flex flex-col gap-1 text-sm">
    <NavigationMenuLabel class="leading-none font-medium">
      Introduction
    </NavigationMenuLabel>
    <NavigationMenuDescription class="line-clamp-2 text-muted-foreground">
      Re-usable components built with Kobalte and Tailwind CSS.
    </NavigationMenuDescription>
  </div>
</NavigationMenuLink>
```

## Active Link

Kobalte's link primitive has no `active` prop, so set `data-active` yourself to
style the link for the current page.

```tsx showLineNumbers
<NavigationMenuLink href="/docs" data-active={isActive() ? "" : undefined}>
  Docs
</NavigationMenuLink>
```
