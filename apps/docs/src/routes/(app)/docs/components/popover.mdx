## Usage

```tsx showLineNumbers
import { Button } from "~/components/ui/button"
import {
  Popover,
  PopoverContent,
  PopoverDescription,
  PopoverHeader,
  PopoverTitle,
  PopoverTrigger,
} from "~/components/ui/popover"
```

```tsx showLineNumbers
<Popover>
  <PopoverTrigger as={Button<"button">} variant="outline">
    Open Popover
  </PopoverTrigger>
  <PopoverContent>
    <PopoverHeader>
      <PopoverTitle>Title</PopoverTitle>
      <PopoverDescription>Description text here.</PopoverDescription>
    </PopoverHeader>
  </PopoverContent>
</Popover>
```

## Composition

Use the following composition to build a `Popover`:

```text
Popover
├── PopoverTrigger
└── PopoverContent
```

## Align

Use the `placement` prop on the `Popover` to control the alignment. It accepts `top`,
`right`, `bottom` and `left`, each with an optional `-start` or `-end` suffix for
alignment. Use `gutter` to change the distance from the trigger.
