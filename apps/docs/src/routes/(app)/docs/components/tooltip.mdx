## Usage

```tsx showLineNumbers
import {
  Tooltip,
  TooltipContent,
  TooltipTrigger,
} from "~/components/ui/tooltip"
```

```tsx showLineNumbers
<Tooltip>
  <TooltipTrigger>Hover</TooltipTrigger>
  <TooltipContent>
    <p>Add to library</p>
  </TooltipContent>
</Tooltip>
```

## Composition

Use the following composition to build a `Tooltip`:

```text
Tooltip
├── TooltipTrigger
└── TooltipContent
```

## Side

Use the `placement` prop on the `Tooltip` to change the position of the tooltip. It
accepts `top`, `right`, `bottom` and `left`, each with an optional `-start` or `-end`
suffix for alignment. Use `gutter` to change the distance from the trigger.

## Delay

Tooltips open as soon as the trigger is hovered or focused. Use `openDelay` and
`closeDelay` on the `Tooltip` to change that.

```tsx showLineNumbers
<Tooltip openDelay={700} closeDelay={300}>
  <TooltipTrigger>Hover</TooltipTrigger>
  <TooltipContent>
    <p>Add to library</p>
  </TooltipContent>
</Tooltip>
```
