## Usage

```tsx
import {
  Resizable,
  ResizableHandle,
  ResizablePanel,
} from "~/components/ui/resizable"
```

```tsx showLineNumbers
<Resizable orientation="horizontal">
  <ResizablePanel>One</ResizablePanel>
  <ResizableHandle />
  <ResizablePanel>Two</ResizablePanel>
</Resizable>
```

## Composition

Use the following composition to build a `Resizable`:

```text
Resizable
├── ResizablePanel
├── ResizableHandle
└── ResizablePanel
```

## Vertical

Use `orientation="vertical"` for vertical resizing. Panels are sized with
`flex-basis` percentages, so give a vertical group a definite height.

## API Reference

See the [Corvu Resizable documentation](https://corvu.dev/docs/primitives/resizable/) for the full API reference.

### Resizable

The `Resizable` component is the panel group. It renders a `div` and lays its
panels out along `orientation`.

| Prop             | Type                         | Default        |
| ---------------- | ---------------------------- | -------------- |
| `orientation`    | `"horizontal" \| "vertical"` | `"horizontal"` |
| `sizes`          | `number[]`                   | -              |
| `initialSizes`   | `Size[]`                     | -              |
| `onSizesChange`  | `(sizes: number[]) => void`  | -              |
| `keyboardDelta`  | `Size`                       | `0.1`          |
| `class`          | `string`                     | -              |

### ResizablePanel

The `ResizablePanel` component is a single panel of the group. Sizes are
fractions of the group, so `0.25` is a quarter of it. A `Size` is that
fraction or a pixel string such as `"200px"` — percentages are not accepted.

| Prop          | Type                     | Default |
| ------------- | ------------------------ | ------- |
| `initialSize` | `Size`                   | -       |
| `minSize`     | `Size`                   | `0`     |
| `maxSize`     | `Size`                   | `1`     |
| `collapsible` | `boolean`                | `false` |
| `onResize`    | `(size: number) => void` | -       |
| `class`       | `string`                 | -       |

### ResizableHandle

The `ResizableHandle` component is the draggable separator between two panels.
It renders a `button` with `role="separator"` and is operable with the arrow
keys.

| Prop         | Type      | Default |
| ------------ | --------- | ------- |
| `withHandle` | `boolean` | `false` |
| `disabled`   | `boolean` | -       |
| `class`      | `string`  | -       |
