## init

Use the `init` command to set up a project. It writes a `components.json`, seeds
your stylesheet with the base color's tokens, and adds the `cn` util.

```bash
npx shadcn-solidjs@latest init
```

You will be asked which base color, icon library and style to use:

```txt
Which base color would you like to use? › zinc
Which icon library would you like to use? › Lucide
Which style would you like to use? › Nova
```

Paths are not asked for. `init` reads the alias your project already declares —
`imports` in `deno.json`, or `paths` in `tsconfig.json` — and finds the
stylesheet that imports Tailwind, so the generated `components.json` matches the
project rather than imposing a layout on it. Both need to exist first; `init`
reports what is missing if they don't.

To change where components are written, edit the `aliases` in
`components.json` afterwards.

### Options

```txt
-c, --cwd <cwd>            the working directory. defaults to the current directory.
-y, --yes                  skip confirmation prompt.
-d, --defaults             use default configuration.
-f, --force                force overwrite of existing configuration.
-s, --silent               mute output.
-b, --base-color <color>   the base color to use.
    --style <style>        the style to use.
    --css-variables        use css variables for theming. (default)
    --no-css-variables     use utility classes for theming.
```

## add

Use the `add` command to add components and their dependencies to your project.

```bash
npx shadcn-solidjs@latest add button card dialog
```

Components are named, not picked from a list — pass one or more names, a URL, or
`--all` to add everything:

```bash
npx shadcn-solidjs@latest add --all
```

Files that already exist and differ are left alone and reported, so a re-run
never overwrites your edits silently. Pass `--overwrite` when you do want them
replaced, or `--dry-run` to see what would change first.

### Options

```txt
-c, --cwd <cwd>      the working directory. defaults to the current directory.
-o, --overwrite      overwrite existing files.
-a, --all            add all available components.
-p, --path <path>    the path to add the component to.
-s, --silent         mute output.
    --dry-run        preview the changes without writing files.
```
