---
title: CLI
description: Use the shadcn CLI to add components to your project.
---

Components are installed with the [shadcn CLI](https://ui.shadcn.com/docs/cli)
from the shadcn-solidjs registry. Every item is a standard registry item, so
the CLI copies the files into your project, rewrites their imports to your
aliases and installs the packages they need.

## init

Use the `init` command to set up a project, pointed at the base color you want.
It writes `components.json`, adds the theme variables to the stylesheet that
imports Tailwind, and adds the `cn` util.

```bash
npx shadcn@latest init https://shadcn-solidjs.com/r/init/neutral.json
```

The base colors are `neutral`, `stone`, `zinc`, `mauve`, `olive`, `mist` and
`taupe`. `init` reads the `~` alias from `tsconfig.json` and finds the
stylesheet that imports Tailwind, so both need to exist first.

## registries

Add the registry to `components.json` once. The URL picks the style and the
icon library, and every component, along with the components it depends on, is
installed in them:

```json title="components.json"
{
  "registries": {
    "@shadcn-solidjs": "https://shadcn-solidjs.com/r/styles/nova/icons/lucide/{name}.json"
  }
}
```

| Part of the URL   | Values                                                              |
| ----------------- | ------------------------------------------------------------------- |
| `styles/<style>`  | `nova`, `vega`, `maia`, `lyra`, `mira`, `luma`, `sera`, `rhea`      |
| `icons/<library>` | `lucide`, `tabler`, `ph` (Phosphor), `ri` (Remix Icon), `hugeicons` |

To move to another style or icon library later, change the URL and add the
components again with `--overwrite`.

## add

Use the `add` command to add components and their dependencies to your
project.

```bash
npx shadcn@latest add @shadcn-solidjs/button @shadcn-solidjs/card @shadcn-solidjs/dialog
```

Pass `--dry-run` to see what would change first, or `--diff` to compare the
files you have with the registry's.

```bash
npx shadcn@latest add @shadcn-solidjs/button --diff
```

## Themes

The accent themes layer on top of a base color. Add one by its URL:

```bash
npx shadcn@latest add https://shadcn-solidjs.com/r/themes/blue.json
```

The accents are `amber`, `blue`, `cyan`, `emerald`, `fuchsia`, `green`,
`indigo`, `lime`, `orange`, `pink`, `purple`, `red`, `rose`, `sky`, `teal`,
`violet` and `yellow`.

## search and view

`search` lists the registry's items and `view` prints one before you add it:

```bash
npx shadcn@latest search @shadcn-solidjs -q dialog
npx shadcn@latest view @shadcn-solidjs/dialog
```
