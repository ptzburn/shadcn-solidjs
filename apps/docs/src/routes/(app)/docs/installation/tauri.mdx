description: Install and configure Tauri.
---

<Steps>

### Create project

Start by creating a new Tauri project:

```bash
npm create tauri-app@latest
```

When asked make sure to use Solid:

```txt showLineNumbers
✔ Project name · tauri-app
✔ Choose which language to use for your frontend · TypeScript / JavaScript
✔ Choose your UI template · Solid
✔ Choose your UI flavor · TypeScript
```

### Add Tailwind CSS

```bash
npm install tailwindcss @tailwindcss/vite
```

Replace everything in the global stylesheet the template created under `src/`
with the following:

```css
@import "tailwindcss";
```

`init` looks for the stylesheet that imports Tailwind and writes the theme
variables into it, so this file has to exist before you run the CLI.

### Edit tsconfig.json file

Add the following code to the `tsconfig.json` file to resolve paths:

```ts title="tsconfig.json" {4-9} showLineNumbers
{
  "compilerOptions": {
    // ...
    "baseUrl": ".",
    "paths": {
      "~/*": [
        "./src/*"
      ]
    }
    // ...
  }
}
```

If your project splits its TypeScript configuration across `tsconfig.app.json`
and friends, add the alias to the root `tsconfig.json` as well — that is the
file the CLI reads.

### Update vite.config.ts

Install `@types/node` so you can import `path` without an error, and
`unplugin-icons`, which resolves the `~icons/…` imports components use:

```bash
npm install -D @types/node unplugin-icons
```

```ts title="vite.config.ts" showLineNumbers {1-4,9-11,13-17}
import path from "path"

import tailwindcss from "@tailwindcss/vite"
import Icons from "unplugin-icons/vite"
import solid from "vite-plugin-solid"
import { defineConfig } from "vite"

export default defineConfig({
  plugins: [
    solid(),
    tailwindcss(),
    Icons({ compiler: "solid", autoInstall: true }),
  ],
  resolve: {
    alias: {
      "~": path.resolve(__dirname, "./src"),
    },
  },
})
```

Keep any Tauri-specific options the template already put in this file, such as
`clearScreen`, `server` and `envPrefix`.

### Run the CLI

Run the `shadcn-solidjs` init command to setup your project:

```bash
npx shadcn-solidjs@latest init
```

### Configure components.json

You will be asked which base color, icon library and style to use:

```txt showLineNumbers
Which base color would you like to use? › zinc
Which icon library would you like to use? › Lucide
Which style would you like to use? › Nova
```

`init` reads the path alias your project already declares and finds the
stylesheet that imports Tailwind, so it does not ask where those live. The
answers and the detected paths are written to `components.json`.

### That's it

You can now start adding components to your project.

```bash
npx shadcn-solidjs@latest add button
```

The command above will add the `Button` component to your project, along with
the packages it needs. You can then import it like this:

```tsx title="src/App.tsx" {1,6} showLineNumbers
import { Button } from "~/components/ui/button"

export default function App() {
  return (
    <div class="flex min-h-svh flex-col items-center justify-center">
      <Button>Click me</Button>
    </div>
  )
}
```

</Steps>

## Integration into existing projects

If you already have a SolidStart, Vite or Astro project with shadcn-solidjs set up you can add Tauri by simply following the steps provided [here](https://tauri.app/v1/guides/getting-started/setup/integrate/).
