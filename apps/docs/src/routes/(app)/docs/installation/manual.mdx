title: Manual Installation
description: Add dependencies to your project manually.

<Steps>

### Add Tailwind CSS

Components are styled with Tailwind CSS v4. In a Vite project that means the
Vite plugin rather than a PostCSS setup:

```bash
npm install tailwindcss @tailwindcss/vite
```

Tailwind v4 has no `tailwind.config.js`. Everything below is configured in CSS.

### Add dependencies

```bash
npm install class-variance-authority clsx tailwind-merge
npm install -D tw-animate-css unplugin-icons
```

`unplugin-icons` resolves the `~icons/…` imports components use. Each component
also brings its own packages — `@kobalte/core` for most of them, and an
`@iconify-json/*` set for whichever icon library you pick — but the CLI installs
those when you add a component, so you don't need them up front.

### Edit tsconfig.json file

Add the following code to the `tsconfig.json` file to resolve paths:

```ts title="tsconfig.json" {4-9} showLineNumbers
{
  "compilerOptions": {
    // ...
    "baseUrl": ".",
    "paths": {
      "~/*": [
        "./src/*"
      ]
    }
    // ...
  }
}
```

If your setup splits its TypeScript config — Vite scaffolds a `tsconfig.app.json`
— add the alias to both. The root `tsconfig.json` is the one tooling reads.

### Update vite.config.ts

Install `@types/node` so you can import `path` without an error:

```bash
npm i -D @types/node
```

```ts title="vite.config.ts" showLineNumbers
import path from "path"

import tailwindcss from "@tailwindcss/vite"
import Icons from "unplugin-icons/vite"
import solid from "vite-plugin-solid"
import { defineConfig } from "vite"

export default defineConfig({
  plugins: [
    solid(),
    tailwindcss(),
    Icons({ compiler: "solid", autoInstall: true }),
  ],
  resolve: {
    alias: {
      "~": path.resolve(__dirname, "./src"),
    },
  },
})
```

class and Kobalte's `data-kb-theme="dark"`. The `--radius-*` scale is derived
from `--radius`, so changing that one value rounds the whole set.

### Add a cn helper

Components use a `cn` helper to merge Tailwind classes. Define it in
`src/lib/utils.ts`:

```ts title="src/lib/utils.ts" showLineNumbers
import type { ClassValue } from "clsx"
import { clsx } from "clsx"
import { twMerge } from "tailwind-merge"

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}
```

You can now start adding components to your project.
