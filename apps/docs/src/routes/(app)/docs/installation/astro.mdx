title: Astro
description: Install and configure Astro.
---

<Steps>

### Create project

Start by creating a new Astro project:

```bash
npm create astro@latest
```

### Configure your Astro project

You will be asked a few questions to configure your project:

```txt showLineNumbers
- Where should we create your new project? ./shining-saturn
- How would you like to start your new project? Include sample files
- Do you plan to write TypeScript? Yes
- How strict should TypeScript be? Strict
```

### Add Solid to your project

Install Solid using the Astro CLI:

```bash
npx astro add solid
```

<Callout class="mt-4">

Answer `Yes` to all the question prompted by the CLI when installing Solid.

</Callout>

### Add Tailwind CSS to your project

Install Tailwind CSS using the Astro CLI:

```bash
npx astro add tailwind
```

<Callout class="mt-4">

Answer `Yes` to all the question prompted by the CLI when installing Tailwind CSS.

</Callout>

This registers the `@tailwindcss/vite` plugin in `astro.config.mjs` and creates a
stylesheet containing `@import "tailwindcss";`. Astro loads it from your layout —
keep that import in place, since `init` writes the theme variables into that file.

### Edit tsconfig.json file

Add the following code to the `tsconfig.json` file to resolve paths:

```ts title="tsconfig.json" {4-9} showLineNumbers
{
  "compilerOptions": {
    // ...
    "baseUrl": ".",
    "paths": {
      "~/*": [
        "./src/*"
      ]
    }
    // ...
  }
}
```

### Register unplugin-icons

Components import their icons from `~icons/…`, which `unplugin-icons` resolves.
Astro runs on Vite, so the plugin goes in the `vite` block alongside Tailwind:

```bash
npm install -D unplugin-icons
```

```js title="astro.config.mjs" showLineNumbers {3,9}
import solid from "@astrojs/solid-js"
import tailwindcss from "@tailwindcss/vite"
import Icons from "unplugin-icons/vite"
import { defineConfig } from "astro/config"

export default defineConfig({
  integrations: [solid()],
  vite: {
    plugins: [tailwindcss(), Icons({ compiler: "solid", autoInstall: true })],
  },
})
```

### Run the CLI

Run the `shadcn-solidjs` init command to setup your project:

```bash
npx @ptzburn/shadcn-solidjs@latest init
```

### Configure components.json

You will be asked which base color, icon library and style to use:

```txt showLineNumbers
Which base color would you like to use? › zinc
Which icon library would you like to use? › Lucide
Which style would you like to use? › Nova
```

`init` reads the path alias your project already declares and finds the
stylesheet that imports Tailwind, so it does not ask where those live. The
answers and the detected paths are written to `components.json`.

### That's it

You can now start adding components to your project.

```bash
npx @ptzburn/shadcn-solidjs@latest add button
```

The command above will add the `Button` component to your project, along with
the packages it needs. You can then import it like this:

```astro {2,10} showLineNumbers
---
import { Button } from "~/components/ui/button"
---

<html lang="en">
	<head>
		<title>Astro</title>
	</head>
	<body>
		<Button>Hello World</Button>
	</body>
</html>
```

<Callout class="mt-4">

Solid components in Astro need a [client directive](https://docs.astro.build/en/reference/directives-reference/#client-directives) to be interactive — `<Button client:load>` for example. Without one Astro renders the markup and ships no JavaScript for it.

</Callout>

</Steps>
