---
title: Vite
description: Install and configure Vite.
---

<Steps>

### Create project

Start by creating a new Vite project:

```bash
npm create vite@latest
```

When asked make sure to use Solid:

```txt showLineNumbers
✔ Project name: ... vite-project
✔ Select a framework: › Solid
✔ Select a variant: › TypeScript
```

### Add Tailwind CSS

```bash
npm install tailwindcss @tailwindcss/vite
```

Replace everything in `src/index.css` with the following:

```css title="src/index.css"
@import "tailwindcss";
```

`init` looks for the stylesheet that imports Tailwind and writes the theme
variables into it, so this file has to exist before you run the CLI.

### Edit tsconfig.json file

Vite splits its TypeScript configuration across several files, and
`tsconfig.json` ships with no `compilerOptions` at all. Add the alias there —
that is the file the CLI reads:

```ts title="tsconfig.json" {11-16} showLineNumbers
{
  "files": [],
  "references": [
    {
      "path": "./tsconfig.app.json"
    },
    {
      "path": "./tsconfig.node.json"
    }
  ],
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "~/*": ["./src/*"]
    }
  }
}
```

### Edit tsconfig.app.json file

Add the same alias to `tsconfig.app.json` so your editor resolves the imports:

```ts title="tsconfig.app.json" {4-9} showLineNumbers
{
  "compilerOptions": {
    // ...
    "baseUrl": ".",
    "paths": {
      "~/*": [
        "./src/*"
      ]
    }
    // ...
  }
}
```

### Update vite.config.ts

Install `@types/node` so you can import `path` without an error, and
`unplugin-icons`, which resolves the `~icons/…` imports components use:

```bash
npm install -D @types/node unplugin-icons
```

```ts title="vite.config.ts" showLineNumbers {1-4,8-10,12-16}
import path from "path"

import tailwindcss from "@tailwindcss/vite"
import Icons from "unplugin-icons/vite"
import solid from "vite-plugin-solid"
import { defineConfig } from "vite"

export default defineConfig({
  plugins: [
    solid(),
    tailwindcss(),
    Icons({ compiler: "solid", autoInstall: true }),
  ],
  resolve: {
    alias: {
      "~": path.resolve(__dirname, "./src"),
    },
  },
})
```

### Run the CLI

Run the `shadcn-solidjs` init command to setup your project:

```bash
npx @ptzburn/shadcn-solidjs@latest init
```

### Configure components.json

You will be asked which base color, icon library and style to use:

```txt showLineNumbers
Which base color would you like to use? › zinc
Which icon library would you like to use? › Lucide
Which style would you like to use? › Nova
```

`init` reads the path alias your project already declares and finds the
stylesheet that imports Tailwind, so it does not ask where those live. The
answers and the detected paths are written to `components.json`.

### That's it

You can now start adding components to your project.

```bash
npx @ptzburn/shadcn-solidjs@latest add button
```

The command above will add the `Button` component to your project, along with
the packages it needs. You can then import it like this:

```tsx title="src/App.tsx" {1,6} showLineNumbers
import { Button } from "~/components/ui/button"

export default function App() {
  return (
    <div class="flex min-h-svh flex-col items-center justify-center">
      <Button>Click me</Button>
    </div>
  )
}
```

</Steps>
