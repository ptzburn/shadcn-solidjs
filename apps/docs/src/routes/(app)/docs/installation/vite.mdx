---
title: Vite
description: Install and configure Vite.
---

<Steps>

### Create project

Start by creating a new Vite project:

```bash
npm create vite@latest
```

When asked make sure to use Solid:

```txt showLineNumbers
✔ Project name: ... vite-project
✔ Select a framework: › Solid
✔ Select a variant: › TypeScript
```

### Add Tailwind and its configuration

Install `tailwindcss` and its peer dependencies, then generate your `tailwind.config.js` and `postcss.config.js` files:

```bash
npm install -D tailwindcss@3 postcss autoprefixer
npx tailwindcss init -p
```

### Edit tsconfig.json file

Add the following code to the `tsconfig.json` file to resolve paths:

```ts {4-9} showLineNumbers
{
  "compilerOptions": {
    // ...
    "baseUrl": ".",
    "paths": {
      "~/*": [
        "./src/*"
      ]
    }
    // ...
  }
}
```

### Update vite.config.ts

Add the following code to the `vite.config.ts` so your app can resolve paths without error

```bash
# (so you can import "path" without error)
npm i -D @types/node
```

```ts showLineNumbers
import path from "path"

import solid from 'vite-plugin-solid';
import { defineConfig } from "vite"

export default defineConfig({
  plugins: [solid()],
  resolve: {
    alias: {
      "~": path.resolve(__dirname, "./src")
    }
  }
})
```

### Run the CLI

Run the `shadcn-solidjs` init command to setup your project:

```bash
npx shadcn-solidjs@latest init
```

### Configure components.json

You will be asked which base color, icon library and style to use:

```txt showLineNumbers
Which base color would you like to use? › zinc
Which icon library would you like to use? › Lucide
Which style would you like to use? › Nova
```

`init` reads the path alias your project already declares and finds the
stylesheet that imports Tailwind, so it does not ask where those live. The
answers and the detected paths are written to `components.json`.

### That's it

You can now start adding components to your project.

```bash
npx shadcn-solidjs@latest add button
```

The command above will add the `Button` component to your project. You can then import it like this:

```tsx {1,6} showLineNumbers
import { Button } from "~/components/ui/button"

export default function Home() {
  return (
    <div>
      <Button>Click me</Button>
    </div>
  )
}
```

</Steps>
