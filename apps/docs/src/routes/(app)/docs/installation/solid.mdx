---
title: Solid
description: Install and configure a Solid 2.0 project.
---

<Steps>

### Create project

Start by creating a new project with the Solid CLI:

```bash
npm init solid@latest
```

When asked, pick **Solid 2.0** and a template. The `with-tailwindcss` template
already has Tailwind CSS wired up:

```txt showLineNumbers
✔ Project Name … my-app
✔ What type of project would you like to create? › Solid 2.0 (RC)
✔ Use Typescript? … yes
✔ Which template would you like to use? › with-tailwindcss
```

The `basic` and `fullstack` templates work just as well — add Tailwind CSS
in the next step. `@kobalte/core` 2.0.0-alpha.4 pins its `solid-js` peer to
exactly `2.0.0-rc.16`. npm settles the templates' `solid-js` range on that
release; pnpm installs the newest release candidate instead and warns about
Kobalte's peer. The components are tested against both, so the warning is safe
to ignore.

### Add Tailwind CSS

If your project already has Tailwind CSS configured, skip this step.

```bash
npm install tailwindcss @tailwindcss/vite
```

Replace everything in `src/App.css` with the following:

```css title="src/App.css"
@import "tailwindcss";
```

`init` looks for the stylesheet that imports Tailwind and writes the theme
variables into it, so this file has to exist before you run the CLI.

### Edit tsconfig.json file

Add the `~` alias to `compilerOptions` — that is the file the CLI reads, and
it is what makes `~/components/ui/...` resolve in your editor:

```ts title="tsconfig.json" {4-7} showLineNumbers
{
  "compilerOptions": {
    // ...
    "baseUrl": ".",
    "paths": {
      "~/*": ["./src/*"]
    }
    // ...
  }
}
```

### Update vite.config.ts

Install `@types/node` so you can import `path` without an error, and
`unplugin-icons`, which resolves the `~icons/…` imports components use:

```bash
npm install -D @types/node unplugin-icons
```

```ts title="vite.config.ts" showLineNumbers {1,4,12,15-19}
import path from "node:path";
import tailwindcss from "@tailwindcss/vite";
import { fileRoutes } from "filesystem-routing/vite";
import Icons from "unplugin-icons/vite";
import solid from "@solidjs/vite-plugin";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [
    solid({ start: true, extensions: [".jsx", ".tsx"] }),
    fileRoutes({ types: true }),
    Icons({ compiler: "solid", autoInstall: true }),
    tailwindcss(),
  ],
  resolve: {
    alias: {
      "~": path.resolve(__dirname, "./src"),
    },
  },
});
```

### Declare the icon module types

The `~icons/…` imports need a module declaration for TypeScript. Add it to
`src/vite-env.d.ts` (unplugin-icons ships one for Solid, but its types still
import from `solid-js` where Solid 2.0 moved them to `@solidjs/web`):

```ts title="src/vite-env.d.ts" showLineNumbers {4-9}
/// <reference types="vite/client" />
/// <reference types="../file-routes.d.ts" />

declare module "~icons/*" {
  import type { ComponentProps, JSX } from "@solidjs/web";

  const component: (props: ComponentProps<"svg">) => JSX.Element;
  export default component;
}
```

### Run the CLI

Set up the project with the `init` command of the shadcn CLI, pointed at the
base color you want:

```bash
npx shadcn@latest init https://shadcn-solidjs.com/r/init/neutral.json
```

The base colors are `neutral`, `stone`, `zinc`, `mauve`, `olive`, `mist` and
`taupe`. `init` writes `components.json`, adds the theme variables to the
stylesheet that imports Tailwind, and adds the `cn` util along with the
packages it needs. It reads the `~` alias from `tsconfig.json`, so that has to
be in place first.

### Add the registry

Add the registry to `components.json`. Its URL picks the style and the icon
library every component is installed in:

```json title="components.json" {3-5} showLineNumbers
{
  // ...
  "registries": {
    "@shadcn-solidjs": "https://shadcn-solidjs.com/r/styles/nova/icons/lucide/{name}.json"
  }
}
```

The styles are `nova`, `vega`, `maia`, `lyra`, `mira`, `luma`, `sera` and
`rhea`, and the icon libraries are `lucide`, `tabler`, `ph` (Phosphor), `ri`
(Remix Icon) and `hugeicons`.

### That's it

You can now start adding components to your project.

```bash
npx shadcn@latest add @shadcn-solidjs/button
```

The command above will add the `Button` component to your project, along with
the packages it needs. You can then import it in any route:

```tsx title="src/routes/index.tsx" {1,6} showLineNumbers
import { Button } from "~/components/ui/button";

export default function Home() {
  return (
    <div class="flex min-h-svh flex-col items-center justify-center">
      <Button>Click me</Button>
    </div>
  );
}
```
