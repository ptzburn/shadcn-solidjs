---
title: Solid
description: Install and configure a Solid 2.0 project.
---

<Steps>

### Create project

Start by creating a new project with the Solid CLI:

```bash
npm init solid@latest
```

When asked, pick **Solid 2.0** and a template. The `with-tailwindcss` template
already has Tailwind CSS wired up:

```txt showLineNumbers
✔ Project Name … my-app
✔ What type of project would you like to create? › Solid 2.0 (RC)
✔ Use Typescript? … yes
✔ Which template would you like to use? › with-tailwindcss
```

The `basic` and `fullstack` templates work just as well — add Tailwind CSS
in the next step.

<Callout title="Server-side rendering">
  With `solid-js@2.0.0-rc.0` and `@kobalte/core@2.0.0-alpha.0` — the versions
  the components are built and tested against — the library does not yet work
  reliably with server-side rendering enabled. Stay client-rendered for now:
  answer no if the CLI offers to enable SSR, and leave `ssr` off in the
  `solid()` options of `vite.config.ts` (the `fullstack` template ships with
  `ssr: true` — set it to `false`). Newer releases of either package may
  resolve this, so if you are on later versions it is worth trying with SSR
  on.
</Callout>

### Add Tailwind CSS

If your project already has Tailwind CSS configured, skip this step.

```bash
npm install tailwindcss @tailwindcss/vite
```

Replace everything in `src/App.css` with the following:

```css title="src/App.css"
@import "tailwindcss";
```

`init` looks for the stylesheet that imports Tailwind and writes the theme
variables into it, so this file has to exist before you run the CLI.

### Edit tsconfig.json file

Add the `~` alias to `compilerOptions` — that is the file the CLI reads, and
it is what makes `~/components/ui/...` resolve in your editor:

```ts title="tsconfig.json" {4-7} showLineNumbers
{
  "compilerOptions": {
    // ...
    "baseUrl": ".",
    "paths": {
      "~/*": ["./src/*"]
    }
    // ...
  }
}
```

### Update vite.config.ts

Install `@types/node` so you can import `path` without an error, and
`unplugin-icons`, which resolves the `~icons/…` imports components use:

```bash
npm install -D @types/node unplugin-icons
```

```ts title="vite.config.ts" showLineNumbers {1,4,12,15-19}
import path from "node:path"
import tailwindcss from "@tailwindcss/vite"
import { fileRoutes } from "filesystem-routing/vite"
import Icons from "unplugin-icons/vite"
import solid from "@solidjs/vite-plugin"
import { defineConfig } from "vite"

export default defineConfig({
  plugins: [
    solid({ start: true, extensions: [".jsx", ".tsx"] }),
    fileRoutes({ types: true }),
    Icons({ compiler: "solid", autoInstall: true }),
    tailwindcss(),
  ],
  resolve: {
    alias: {
      "~": path.resolve(__dirname, "./src"),
    },
  },
})
```

### Run the CLI

Run the `shadcn-solidjs` init command to setup your project:

```bash
npx @ptzburn/shadcn-solidjs@beta init
```

### Configure components.json

You will be asked which base color and icon library to use:

```txt showLineNumbers
Which base color would you like to use? › zinc
Which icon library would you like to use? › Lucide
```

`init` reads the path alias your project already declares and finds the
stylesheet that imports Tailwind, so it does not ask where those live. The
answers and the detected paths are written to `components.json`.

### That's it

You can now start adding components to your project.

```bash
npx @ptzburn/shadcn-solidjs@beta add button
```

The command above will add the `Button` component to your project, along with
the packages it needs. You can then import it in any route:

```tsx title="src/routes/index.tsx" {1,6} showLineNumbers
import { Button } from "~/components/ui/button"

export default function Home() {
  return (
    <div class="flex min-h-svh flex-col items-center justify-center">
      <Button>Click me</Button>
    </div>
  )
}
```

</Steps>
