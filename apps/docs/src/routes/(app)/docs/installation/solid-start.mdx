title: SolidStart
description: Install and configure SolidStart.
---

<Steps>

### Create project

Start by creating a new SolidStart project:

```bash
npm init solid@latest
```

Choose **SolidStart** when asked what kind of project to create, and answer yes
to TypeScript.

### Add Tailwind CSS

If the template you picked already set Tailwind up, skip this step.

```bash
npm install tailwindcss @tailwindcss/vite
```

Create `src/app.css` — or replace it if the template made one — with:

```css title="src/app.css"
@import "tailwindcss";
```

Import it from `src/app.tsx`:

```tsx title="src/app.tsx" {3} showLineNumbers
import { Router } from "@solidjs/router"
import { FileRoutes } from "@solidjs/start/router"
import "./app.css"
```

`init` looks for the stylesheet that imports Tailwind and writes the theme
variables into it, so this file has to exist before you run the CLI.

### Update vite.config.ts

SolidStart 2 is configured through `vite.config.ts`. Add the Tailwind plugin and
`unplugin-icons`, which resolves the `~icons/…` imports components use:

```bash
npm install -D unplugin-icons
```

```ts title="vite.config.ts" showLineNumbers {2-3,8-9}
import { solidStart } from "@solidjs/start/config"
import tailwindcss from "@tailwindcss/vite"
import Icons from "unplugin-icons/vite"
import { defineConfig } from "vite"

export default defineConfig({
  plugins: [
    tailwindcss(),
    Icons({ compiler: "solid", autoInstall: true }),
    solidStart(),
  ],
})
```

### Edit tsconfig.json file

SolidStart's templates already map `~/*` to `./src/*`. If yours does not, add it
— the CLI reads this alias to decide where components go:

```ts title="tsconfig.json" {4-9} showLineNumbers
{
  "compilerOptions": {
    // ...
    "baseUrl": ".",
    "paths": {
      "~/*": [
        "./src/*"
      ]
    }
    // ...
  }
}
```

### Run the CLI

Run the `shadcn-solidjs` init command to setup your project:

```bash
npx shadcn-solidjs@latest init
```

### Configure components.json

You will be asked which base color, icon library and style to use:

```txt showLineNumbers
Which base color would you like to use? › zinc
Which icon library would you like to use? › Lucide
Which style would you like to use? › Nova
```

`init` reads the path alias your project already declares and finds the
stylesheet that imports Tailwind, so it does not ask where those live. The
answers and the detected paths are written to `components.json`.

### Fonts

[Inter](https://rsms.me/inter/) is a good default, but any font works.

**1. Install the fontsource package:**

```bash
npm install @fontsource/inter
```

**2. Import the font in `src/app.tsx`:**

```tsx title="src/app.tsx" {1} showLineNumbers
import "@fontsource/inter"
import "./app.css"
```

**3. Point `--font-sans` at it in `src/app.css`:**

Tailwind v4 is configured in CSS, so this replaces the `theme.extend.fontFamily`
block a v3 `tailwind.config` would have carried:

```css title="src/app.css" showLineNumbers
@import "tailwindcss";

@theme inline {
  --font-sans: Inter, ui-sans-serif, system-ui, sans-serif;
}
```

### App structure

A typical SolidStart app looks like this:

```txt {7-11,15-16}
.
├── public
│   ├── favicon.ico
│   └── ...
├── src
│   ├── components
│   │   ├── ui
│   │   │   ├── button.tsx
│   │   │   ├── input.tsx
│   │   │   └── ...
│   │   ├── main-nav.tsx
│   │   ├── page-header.tsx
│   │   └── ...
│   ├── lib
│   │   └── utils.ts
│   ├── routes
│   │   ├── [...404].tsx
│   │   ├── index.tsx
│   │   └── ...
│   ├── app.css
│   ├── app.tsx
│   └── ...
├── vite.config.ts
└── ...
```

- UI components go in `components/ui`.
- Other components such as `<PageHeader />` or `<MainNav />` go in `components`.
- `lib` holds utilities, including the `cn` helper in `utils.ts`.

### That's it

You can now start adding components to your project.

```bash
npx shadcn-solidjs@latest add button
```

The command above will add the `Button` component to your project, along with
the packages it needs. You can then import it like this:

```tsx title="src/routes/index.tsx" {1,6} showLineNumbers
import { Button } from "~/components/ui/button"

export default function Home() {
  return (
    <div class="flex min-h-svh flex-col items-center justify-center">
      <Button>Click me</Button>
    </div>
  )
}
```
